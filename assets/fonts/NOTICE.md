# NatoCheck font assets

These unchanged WOFF2 assets are reused from the owner's existing Eventhacker
website repository, `magnetix-cgn/eventhacker-website/public/assets/fonts/`.
They were delivered through the configured private AgentUp and verified by
complete readback before integration.

**Eventhacker Display Bold 1.0**: Copyright 2026 Eventhacker. Original geometric
outlines created for Eventhacker. The upstream source is
`scripts/build_eventhacker_font.py`; its documentation is
`docs/eventhacker-display.md`. This original display design is distinct from
Ethnocentric. Lowercase uses small capitals. It is used for the NatoCheck
wordmark, headings and large game figures.

**Montserrat variable**: Copyright 2024 The Montserrat.Git Project Authors.
This unmodified companion face is used for body text and controls. Its SIL Open
Font License 1.1 is included in `montserrat-OFL.txt`. The existing upstream WOFF2
conversion is reused without changing glyphs or the family identity.
